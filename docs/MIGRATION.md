# 旧片段迁移与回退

迁移对象是原有的 `20261012180000-ogstyle` 代码片段。先确认启用内容与已核对源码一致，再备份片段、插件启用状态及可用的图谱参数。安装星图时仅停用这个片段，不删除片段内容，不修改其他片段或笔记。

星图首次启动读取同一窗口的 `og-physics-v1` 参数，并写入 `data/storage/petal/siyuan-xingtu/settings.json`。如果已经存在插件参数，则优先使用插件参数。原有浏览器存储保留。代码片段仍启用时，星图会提示并停止接入，避免双重补丁；片段已停用、旧运行实例仍存在时，星图会调用旧实例的清理方法后再接入。

正常停用星图只恢复原生效果，不会自动重新启用旧片段。如需回退到旧版：先停用星图，再启用备份的旧片段。旧实例资源会由插件的停用流程释放；只有窗口仍运行旧版本代码且无法正常清理时才需要重载，重载前应先确认输入已经保存。

迁移过程保留侧边备注插件的关闭状态。独立测试工作区只使用合成笔记，不复制正式笔记。

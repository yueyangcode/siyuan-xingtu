# 测试范围

0.1.1 首次公开发布只修正插件设置页的默认左右分栏，补充真实图谱、参数面板及插件设置截图。图谱、物理布局和生长动画代码与下述 0.1.0 验证基线一致。0.1.1 另行通过 12 项自动测试、构建与包结构检查，并在独立思源窗口中检查设置页与图谱显示；未重复执行十分钟压力测试。

星图 0.1.0 于 2026-11-07 至 2026-11-08 在 Windows、思源 3.8.7 独立工作区及桌面浏览器中验证。工作区仅含合成笔记，未使用正式笔记做压力测试。

- 12 项自动测试通过：参数归一化、旧参数迁移与优先级、不兼容接口、旧片段冲突保护、异步加载中停用、滑块保存合并，以及 50/500/2000 节点物理线程和时间轴后台暂停。
- 同一图谱、固定坐标、相同缩放下，旧片段与插件截图差异为 0 像素。核对了标签数量、节点半径、背景颜色和相机；这是确定性视觉对照，不代表任意动态帧都应逐像素相同。
- 50 次运行实例启停后，已创建的 100 个布局 Worker 全部终止，活动 Worker 和 Blob URL 均为 0，原生方法逐项恢复。该阶段浏览器全局 DOM/监听器计数有一次增长，未据此声称全局零残留；后续长时阶段计数稳定如下。
- 10.04 分钟、60 轮混合运行：交替 51/500/2000 节点、缩放、设置开关、后台切换和运行实例重建。未捕获脚本错误，后台暂停检查中位置更新为 0；同时活动 Worker 最多 2 个，对应全局和局部图谱。
- 混合运行 12 次垃圾回收后采样，JS 堆为 39.00–39.22 MiB，监听器为 666–666，DOM 节点为 5461–5462，未发现随轮次持续增长。
- 真实指针悬停、节点拖拽、滚轮缩放、生长动画暂停/跳转/退出通过；实际插件 API 停用/启用 5 次后参数保留。局部图谱 7 个节点显示 7 个标签，稳定后 1.2 秒内新增绘制帧为 0。
- 在隔离工作区完整演练旧片段停用后的热迁移：旧运行实例释放，星图接入；测试参数连接距离 175、排斥力 520 正确保留，无需重载笔记页面。

尚未覆盖整夜运行、所有操作系统、所有主题、所有思源版本及全部其他插件组合。图谱内部接口存在版本耦合，未来思源升级需重新验证；十分钟测试不能证明永不泄漏或卡顿。图谱生长动画使用创建时间与当前引用关系，不保存历史图谱快照。
